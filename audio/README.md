The supplied loop was transcoded to mono 44.1 kHz / 64 kbps MP3 for a small local download (about 463 KB). No melody changes were made. MP3 encoding can introduce a small loop-boundary gap. This is a freely licensed fantasy instrumental; no Lord of the Rings soundtrack recording is included. Creator credit is also shown next to the music controls.

Quiz music is off by default and is controlled separately from short sound effects. Turn it on from a user click to allow browser audio, then adjust volume or mute. Only instructor question screens (including local Preview) start the loop. Teaching slides, response reveals, end screens, leaving the room, and hiding the tab stop it; question music returns when the tab is visible if a question is still active. Student question messages never start the loop. Load/decode failures display a message and leave the review usable. The local MP3 is included in the service-worker cache.
