Publish to your website

  1. Save your question edits and preview the answers and explanations.
  2. Select Export website file. This downloads authored-questions.js, containing your entire workshop collection.
  3. Open your GitHub upload page ↗, upload the file at the repository root, and commit the replacement. Only people with repository write access can publish.
  4. Once GitHub Pages finishes deploying, refresh the site. The published questions join Review/Exam and the live-session question pool.

Saving here changes your draft only. This page does not sign in to GitHub or publish automatically. Keep previous exports as backups. Exporting an empty collection removes workshop additions when that file is published; built-in questions remain. Images and teaching slides are available in the Gathering Hall presentation editor.
