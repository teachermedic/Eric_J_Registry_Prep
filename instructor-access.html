Workshop password

Choose your instructor password

Create a password here, then publish its configuration file through GitHub. No password is sent to a server or written into the exported file.

  1. Download instructor-access-config.js.
  2. Upload it to the repository root in GitHub and commit the replacement.
  3. After deployment, refresh Question Workshop and enter the password to create or import questions.

Reloading locks the tools again. You can also select Lock Question Workshop; unlocks expire after 30 minutes. Reset a forgotten password by publishing a new configuration.

This is a browser-side deterrent for casual use of creation tools. It cannot stop someone who modifies browser code, and does not make published code or questions confidential. Anyone can generate a configuration locally, but only repository editors can publish it. Actual private administrator access across devices would require a server-side authentication service. GitHub sign-in remains the control for publishing website changes.
