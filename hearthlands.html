Class league · optional

For two classes to compete, give equivalent quizzes the same session name in Gathering Hall’s More options. The league compares their best accuracy across shared sessions. Repeating a quiz can improve a score but does not add extra league points.

All classes help: 100 correct answers build a shelter, 250 a timber hall, and 500 the Great Gathering Hall.
