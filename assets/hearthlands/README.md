# Illustrated Hearthlands assets

- `island-base.webp`: the owner's supplied `image.png` (1536×1024), encoded as WebP at quality 90. The original composition is unchanged; all buildings are separate overlays.
- `building-atlas.webp`: generated with the built-in image-generation tool, using the owner's island as the visual reference. The original generated atlas is 1774×887 with alpha; this WebP copy uses quality 94 and retains transparency.

The atlas has six building types and three levels. Sprite source rectangles are defined in `hearthlands-engine.js`; the map scales them in the original background's coordinate system. The seventh plot uses the level-three garden as a free celebration garden after the six main plots are built. No source image was painted over or animated. Existing save identifiers, upgrade prices and scores are retained.

- `preview.webp`: a local browser-test screenshot of the fully upgraded island, included for pull-request review. It shows a test fixture, not earned student progress.

## Generation prompt

The attached image is STYLE AND CAMERA REFERENCE ONLY, not the edit target: preserve the user's island as a separate background; generate matching standalone buildings. Create exactly 18 separate illustrated game assets arranged in a STRICT regular grid: SIX COLUMNS and THREE ROWS, evenly spaced equal-size cells, transparent background across the entire atlas. Wide 2:1 canvas. Camera: elevated isometric toy diorama matching the reference's terrain plots; consistent scale, light from upper left, softly painted 3D storybook texture, cozy green/beige/copper fantasy village. Each object completely inside its cell with generous transparent gutters; bottom of each object aligned on same ground baseline within its row; never touch neighboring cells. NO TEXT, NO labels, NO grid lines, NO characters, NO landscape background. Columns from left to right: 1 round-door woodland Lodge, 2 cozy book-filled Library, 3 herbal healer's Infirmary identified by a small green cross, 4 stone Watchtower with green pointed copper roof, 5 raised vegetable Garden with small greenhouse, 6 small stone arch Bridge over a tiny self-contained blue pond. ROW ONE: small simple level-one starter version of all six types. ROW TWO: larger more detailed level-two version of the same six in exactly the same column order, adding porch, shelves, pots, windows or trim. ROW THREE: grand fully upgraded level-three version of those same six in exactly the same order, with added wings, extra storey or abundant flowers and decorations. Each building should fit on one small diamond-shaped footprint, objects readable at thumbnail size, opaque interior colors with true transparent surroundings. This must be a clean usable 6-by-3 sprite sheet, not a full island scene. No cast shadow extending outside a cell. No animation.
